# Klyro

An open-source Digital Logic & Systems simulator for Windows and Web.

Built for students and educators to visualize, simulate and understand digital electronics — from basic gates to complex sequential circuits.

## Features
- Interactive circuit board with real 74LS/74HC series ICs
- Event-driven simulation engine with 4-value logic (0, 1, X, Z)
- K-Map solver with Quine-McCluskey minimization
- Flip-flops, registers, counters, MUX, decoders and more
- FSM / ASM chart builder
- HDL export (VHDL / Verilog)
- Windows desktop app + Web app from a single codebase
